# 单代号时标网络进度计划图生成系统

根据**招标文件**与**工程量清单（BOQ）**，自动生成**单代号（AON）时标网络进度计划图**的完整工程。

输入 PDF → 解析项目工期/里程碑/清单项 → 半自动估算工期 → 建立逻辑关系 → **关键路径法（CPM）** → 输出**时标网络进度计划图（SVG / PNG）**，并提供**浏览器交互式演示版**。

## 功能特性

- **PDF 输入**：解析招标文件（项目名称、开工日期、合同工期、里程碑）与工程量清单（工作项、单位、工程量、紧前关系）。
- **半自动工期估算**：按工效基准表给出建议工期（`工期 = ⌈工程量 ÷ 工效⌉`），支持清单中 `manualDuration` 人工覆盖。
- **自动建立逻辑关系**：优先用清单提供的紧前关系；缺失时按施工顺序模板自动建立 FS 链。
- **关键路径法（CPM）**：正推 ES/EF、反推 LS/LF，计算总时差 TF / 自由时差 FF，识别关键线路。
- **时标网络图渲染**：工作框长度 = 工期，关键工作红色加粗、波浪线标注自由时差、里程碑菱形节点。
- **双格式输出**：SVG（矢量可无损缩放）、PNG（2x 高清位图）、机读结果 JSON。
- **交互式演示版**：浏览器打开即用，表格改工期/紧前关系即时重算重画，带关键线路动画。

## 目录结构

```
├── docs/                  技术方案设计文档
├── demos/                 浏览器交互式演示（单文件 HTML，双击即用）
└── prototype/             可运行原型（Node.js）
    ├── config/            工效基准表 + 施工顺序模板（可配置）
    ├── data/              样例招标文件 / 工程量清单（JSON + 生成的中文 PDF）
    ├── src/               核心源码（解析 / 估算 / 逻辑 / CPM / 布局 / 渲染）
    └── output/            输出示例（时标网络进度计划图 SVG / PNG / JSON）
```

## 快速开始

### 命令行原型

```bash
cd prototype
npm install                # 安装依赖
npm run demo               # 用内置样例 JSON，生成时标网络图 → output/
npm run make-sample-pdf    # 生成样例招标文件.pdf 与工程量清单.pdf
npm run pdf-demo           # PDF 端到端：解析 → 估算 → 关键路径 → 出图
```

指定自己的文件：

```bash
node src/index.js --bid-pdf "你的招标文件.pdf" --boq-pdf "你的工程量清单.pdf"
```

### 交互式演示版

直接双击打开 `demos/交互式演示.html`（或浏览器打开），即可：

- 表格中修改工期 / 紧前关系 / 增删工作，图即时重算重画；
- 「导入JSON工程」导入结构化清单；
- 「▶ 关键线路动画」逐条高亮关键路径；
- 「下载」导出 PNG / SVG。

## 核心算法说明

| 模块 | 文件 | 说明 |
|------|------|------|
| 工期估算 | `src/durationEstimator.js` | `工期 = ⌈工程量 ÷ 工效⌉`，支持固定工期与人工覆盖 |
| 逻辑关系 | `src/logicBuilder.js` | 清洗紧前引用；缺失时按顺序模板兜底 |
| 关键路径 | `src/cpm.js` | 正推/反推，计算 ES/EF/LS/LF/TF/FF，识别关键线路 |
| 时标布局 | `src/layout.js` | X 轴 = 时间，Y 轴用区间图贪心分层避免重叠 |
| SVG 渲染 | `src/svgRenderer.js` | 工作框、波浪线、里程碑、时间轴、图例 |
| PDF 解析 | `src/pdfParser.js` | 行聚类 + 列间隙切分，提取清单与项目信息 |
